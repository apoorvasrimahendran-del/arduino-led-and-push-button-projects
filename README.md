# arduino-led-and-push-button-projects
Arduino LED and Push Button Projects

Today, I worked on a few beginner-level Arduino projects to understand how LEDs and push buttons work together.

I wanted to learn how a button can control an LED, how the LED responds when a button is pressed or released, and how multiple buttons can control the same LED.

These small experiments helped me understand digital inputs, digital outputs, and basic Arduino programming.

Projects

1. LED Control Using a Push Button

In this project, I used a push button to control an LED. Pressing the button turns the LED on, and pressing it again turns the LED off.

Components used:

- Arduino board
- LED
- Push button
- Resistor and connecting wires


2. Two LEDs with One Push Button

Here, I used two LEDs and one push button. When the button is pressed, one LED glows. When the button is released, the other LED glows.

Components used:

- Arduino board
- Two LEDs
- One push button
- Resistors and connecting wires

3. One LED Controlled by Two Push Buttons

In this experiment, I used two push buttons to control a single LED. One button turns the LED on, while the other button turns it off.

Components used:

- Arduino board
- One LED
- Two push buttons
- Resistors and connecting wires


4. Additional LED and Push Button Experiment

This project is another small experiment I completed while practising push-button inputs and LED control.


What I Learned

- How to configure Arduino pins as inputs and outputs.
- How to read push-button inputs.
- How to control LEDs using digital signals.
- How pressing and releasing a button can produce different outputs.
- How to write, test, and organize basic Arduino code.

Technologies Used

- Arduino
- Embedded C/C++ (Arduino programming)
- LEDs and push buttons
- Arduino IDE

Project Status

Completed beginner-level practice projects. I plan to keep learning and build more Arduino and embedded systems projects as I gain experience.
